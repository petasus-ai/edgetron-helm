# edgetron-helm (moved)

The edgetron chart now lives with edgetron itself, in
[PETASUS/edgetron](https://gitlab.tde.sktelecom.com/PETASUS/edgetron) under
`deployment/edgetron`, and is published from that repository's pipeline: chart X.Y.Z
with each edgetron release vX.Y.Z, and 0.0.0-dev from its main branch, to
[petasus-ai/edgestack-helm](https://github.com/petasus-ai/edgestack-helm).

Nothing is published from here any more; the charts this repository published (up to
3.5.1) stay in edgestack-helm.
